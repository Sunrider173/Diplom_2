# Diplom_2

## Тестирование API Stellar Burgers

Этот проект содержит тесты для API сервиса Stellar Burgers.

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск тестов

```bash
# Запуск всех тестов
pytest

# Запуск с генерацией отчета Allure
pytest --alluredir=allure-results

# Генерация и открытие отчета Allure
allure generate allure-results --clean -o allure-report
allure open allure-report
```

### Структура проекта

- `data/` - содержит классы с тестовыми данными
- `tests/` - содержит тестовые файлы
- `conftest.py` - конфигурация pytest с фикстурами
